# Objectif du document

L'objectif de ce document est de définir les termes retenus issus de l'API OpenFDA.

# Problèmes observés

## Problème 1 : product_res_number

Problème identifié sur la ligne "product_res_number", il identifie de manière unique chaque résultat donné par l'API mais n'est pas présent dans le PDF définissant la liste des champs fournis par l'API.

Cela doit être une erreur dans la documentation.

Action : Contacter le responsable collecte des données (OpenFDA) pour clarifier le cas de cette ligne
